Windows — Python 快捷键说明书

适用系统：Windows 10 / Windows 11  |  适用环境：VS Code + Python 3

📌 按键说明：Ctrl = Control 键   Alt = Alt 键   Win = Windows 键
📌 安装提示：访问 python.org 下载安装包，务必勾选 "Add Python to PATH"。

一、VS Code 编辑快捷键

✏️ 基础编辑

功能快捷键
打开命令面板Ctrl + Shift + P
快速打开文件Ctrl + P
保存文件Ctrl + S
撤销Ctrl + Z
重做Ctrl + Shift + Z

🔍 搜索与导航

功能快捷键
当前文件搜索Ctrl + F
全局搜索Ctrl + Shift + F
跳转到行Ctrl + G
返回上一次光标位置Ctrl + -

✂️ 代码编辑

功能快捷键
注释 / 取消注释Ctrl + /
块注释Alt + Shift + A
增加缩进Ctrl + ]
减少缩进Ctrl + [
上移一行Alt + ↑
下移一行Alt + ↓
复制当前行Alt + Shift + ↓
删除当前行Ctrl + Shift + K
多光标添加Alt + 点击
选中所有匹配Ctrl + Shift + L
格式化文档Shift + Alt + F

二、Python 开发专用快捷键

功能快捷键
运行 Python 文件Ctrl + F5
启动调试F5
跳转到定义F12
预览定义Alt + F12
重命名变量/函数F2
快速修复Ctrl + .
参数提示Ctrl + Shift + Space
自动补全Ctrl + Space
切换侧边栏Ctrl + B

三、终端与命令行快捷键

功能快捷键
开/关终端面板Ctrl + `
新建终端Ctrl + Shift + `
中断当前命令Ctrl + C
清屏输入 cls
搜索历史命令F8
上一条 / 下一条命令↑ / ↓
跳转到行首Home
跳转到行尾End
删除整行Esc

四、Python 交互式环境 (REPL)

功能操作
启动 Python终端输入 python 或 py
退出 Pythonexit() 或 Ctrl + Z 再按 Enter
历史命令↑ / ↓
自动补全Tab
查看帮助help()
清屏import os; os.system('cls')

五、窗口与分屏管理

功能快捷键
分屏编辑Ctrl + \
关闭标签页Ctrl + W
恢复关闭的标签Ctrl + Shift + T
打开设置Ctrl + ,
全屏F11
💡 pip 换源（国内用户加速）：
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

💡 路径提示：Windows 用反斜杠 \，建议在 Python 中用正斜杠 / 或原始字符串 r"路径"。

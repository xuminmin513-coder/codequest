Linux — Python 快捷键说明书

适用系统：Ubuntu / Debian / Fedora / Arch 等主流 Linux 发行版  |  适用环境：VS Code + Python 3

📌 按键说明：Ctrl = Control 键   Alt = Alt 键   Super = 系统键（部分 Gnome/KDE 环境）
📌 安装提示：大部分 Linux 系统已预装 Python 3，终端输入 python3 --version 验证。
VS Code 下载：code.visualstudio.com（选择 .deb/.rpm 包）

💡 Linux 用户特别提示：
• 终端输入 python3 启动 Python 3（注意不是 python）
• 安装 pip：sudo apt install python3-pip（Debian/Ubuntu）
• pip 换源（国内加速）：pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
• VS Code 安装后可按 Ctrl + Shift + X 搜索安装 Python 扩展
🐧 不同发行版终端快捷键差异：
• Ubuntu/Gnome：Ctrl + Alt + T 打开终端
• KDE Plasma：Ctrl + Alt + Space 打开 KRunner
• 大部分终端模拟器支持 Ctrl + Shift + C 复制，Ctrl + Shift + V 粘贴

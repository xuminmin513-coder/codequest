HarmonyOS — Python 快捷键说明书

适用系统：HarmonyOS NEXT / 鸿蒙操作系统  |  适用环境：VS Code（PC 端）+ Python 3

📌 关于 HarmonyOS 说明：
HarmonyOS（鸿蒙操作系统）是华为自主研发的分布式操作系统。目前 Python 开发主要在 HarmonyOS 的 PC 端（如 MateBook 系列笔记本）进行， 这些设备运行 HarmonyOS 桌面模式，使用 Ctrl / Alt / Win 键位布局与 Windows 类似。

📌 按键说明：Ctrl = Control 键   Alt = Alt 键   ⌘ = Command 键（部分华为键盘）
📌 安装提示：在 HarmonyOS PC 端前往 python.org 下载安装包。
VS Code 可通过华为应用市场或官网下载。HarmonyOS 平板上可使用 Termux 或在线 Python 环境。

📱 HarmonyOS 特别提示：
• PC 端（MateBook 系列）：键位布局与 Windows 基本相同，以上快捷键在 VS Code for HarmonyOS 中通用
• 平板端：可配合蓝牙键盘使用 VS Code for HarmonyOS，Ctrl 键位与 PC 一致
• 手机端：推荐使用在线 Python 环境（如 CodeRunner、Termux 等）
• pip 换源（国内加速）：pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
• 鸿蒙 PC 端可在华为应用市场搜索 "VS Code" 或 "Python" 获取开发工具

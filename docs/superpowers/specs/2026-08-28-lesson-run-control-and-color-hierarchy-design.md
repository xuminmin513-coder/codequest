# 课程页运行控件与内容颜色层级设计

日期：2026-08-28

## 目标

改善课程页的两个高频使用问题：

1. 运行按钮位于整页右下方，距离代码编辑器过远，使用不方便。
2. 学习说明、示例、题目和提示的视觉样式过于接近，初学者难以快速判断当前内容的用途。

本次改动必须保持现有 iOS 风格的极简外观，同时确保桌面端、手机端和长页面滚动继续正常工作。

## 已确认的视觉方向

### 运行按钮

采用“黑色编辑器内部底部操作栏”方案：

- 编辑器黑框由顶部语言栏、代码区和底部操作栏三部分组成。
- 运行按钮位于底部操作栏右侧。
- 底部操作栏属于黑色编辑器的一部分，但与代码输入区域分隔，因此不会遮挡最后几行代码。
- 运行过程中，同一位置的按钮变为红色“停止”，尺寸和位置不跳动。
- 编辑器顶部继续显示 `Cmd+Enter` 或 `Ctrl+Enter` 快捷键提示。
- 页面原有底部操作区不再显示第二个运行按钮。
- “上一关”“下一关”和“返回复习列表”等导航操作继续位于测试结果区域下方。

### 内容颜色层级

采用柔和的语义色块方案。颜色用于标题、浅色背景和左侧色条；正文仍使用深色文字以保证阅读舒适度。

| 内容类型 | 颜色 | 用途 |
| --- | --- | --- |
| 知识讲解 | 柔和蓝色 | 概念、规则、学习目标和普通讲解 |
| 示例演示 | 柔和紫色 | 示例、演示、代码拆解和观察结果 |
| 本关题目 | 柔和绿色 | 任务、挑战、练习要求和需要玩家完成的目标 |
| 提示 | 柔和橙色 | 行内提示、注意事项和分步提示 |

深色代码块保留现有样式，不跟随外部语义色改变。这样可以让代码始终具有稳定、熟悉的视觉位置。

## 内容识别规则

课程正文继续使用现有 Markdown 数据，不要求逐关手工改写。渲染层根据中英文标题自动添加语义样式：

- 包含“任务”“挑战”“练习”或 `Task`、`Challenge`、`Exercise` 的章节归为题目。
- 包含“示例”“演示”“拆解”或 `Example`、`Demo`、`Walkthrough` 的章节归为示例。
- 引用提示块和课程已有的分步提示归为提示。
- 其他标题和正文归为知识讲解。

匹配不区分英文大小写。无法识别的新标题回退为知识讲解样式，不隐藏内容，也不影响课程运行。

## 组件与样式边界

### `Lesson.jsx`

- 为渲染后的课程章节添加稳定的语义类名。
- 把运行/停止按钮移动到编辑器卡片内部的底部操作栏。
- 页面底部操作区只负责关卡导航，不再包含运行按钮。
- 保留现有运行逻辑、停止逻辑、快捷键、礼花效果和结果抽屉行为。

### `lesson-workspace.css`

- 定义编辑器底部操作栏、运行按钮和停止状态。
- 定义四类课程内容的浅背景、色条和标题颜色。
- 使用现有设计变量，并补充少量紫色与绿色语义变量；颜色对比度必须保证正文可读。
- 在窄屏下保持按钮至少 44 像素高，并避免编辑器、操作栏或结果区横向溢出。

课程数据、Python 运行器、判题规则、存档结构和课程解锁逻辑不属于本次范围。

## 状态与交互

1. 玩家编辑代码时，蓝色“运行代码”按钮始终出现在编辑器右下方的操作栏内。
2. 点击运行后，按钮在原位置切换为红色“停止”。
3. 运行完成、失败或被停止后，按钮恢复为蓝色“运行代码”。
4. 测试结果和运行输出仍显示在编辑器下方的统一结果抽屉内。
5. 通关后继续保留礼花效果和“下一关”操作。

## 无障碍与响应式要求

- 运行和停止按钮继续使用真实的 `button` 元素，并保留清楚的中英文文字。
- 键盘运行快捷键保持可用。
- 颜色不是唯一提示：每个色块必须有文字标题，题目、示例和提示不能只靠颜色区分。
- 手机端按钮点击高度不小于 44 像素。
- 页面在桌面端和手机端均可正常上下滚动。
- 开启减少动态效果时，本次改动不增加新的动画。

## 测试与验收

实施采用测试优先方式，至少覆盖以下行为：

1. 课程页只有一个运行/停止主按钮。
2. 按钮位于编辑器卡片的内部底部操作栏，而不是页面底部导航区。
3. 运行状态仍能切换为停止状态，现有停止逻辑不回退。
4. 中英文任务、挑战、示例和普通讲解可得到正确的语义类名。
5. 行内提示和分步提示使用提示样式。
6. 无法识别的标题安全回退为知识讲解样式。
7. 桌面端和手机端界面均无横向溢出，长页面仍能上下滚动。
8. 现有课程、运行器、安全、存档、礼花与毕业测试全部通过。

## 不在本次范围内

- 不重写 104 个关卡的课程正文。
- 不改变运行结果抽屉的信息结构。
- 不改变题目答案、判题标准或课程顺序。
- 不新增动画、AI 功能或账号功能。
- 不调整课程地图、仪表盘或存档界面。
